# SILTUS · Green Power Hack

**Baldosa piezoeléctrica para aprovechar la energía de las pisadas.**

Propuesta presentada para **Green Power Hack: Soluciones para un mundo sostenible**, en la Facultad de Ingeniería de la **Universidad de Especialidades Espíritu Santo (UEES)**. Se enmarca en la fase de **generación y almacenamiento de energía**.

📄 **[Consultar la propuesta completa en PDF](docs/ecohack.pdf)**

## ¿De qué trata?

SILTUS propone desarrollar una baldosa que transforme la presión de las pisadas en energía eléctrica mediante sensores piezoeléctricos. Está pensada para espacios de alta circulación, como campus universitarios, estaciones de transporte y centros comerciales.

El objetivo es aprovechar esa energía para dispositivos de bajo consumo o almacenarla para su uso posterior. El diseño también busca fomentar el aprendizaje sobre generación de energía y el uso de materiales reciclados.

## Principio de funcionamiento

El efecto piezoeléctrico permite que ciertos materiales generen una carga eléctrica al deformarse bajo presión mecánica. La propuesta distribuye discos piezoeléctricos sobre una base de **30 × 30 cm**, con una cubierta protectora y conexiones hacia un sistema de almacenamiento.

1. Una persona pisa la superficie de la baldosa.
2. La presión deforma los elementos piezoeléctricos, que generan una carga eléctrica.
3. El cableado conduce la energía hacia el sistema de aprovechamiento o almacenamiento previsto.

El circuito de acondicionamiento eléctrico y la integración con la batería o el condensador requieren definición y validación durante el desarrollo del prototipo.

## Componentes y materiales propuestos

| Componente | Función |
| --- | --- |
| Discos piezoeléctricos de 20 mm | Convertir la presión mecánica en carga eléctrica. |
| Cubierta de acrílico | Proteger los elementos internos de suciedad, humedad y desgaste. |
| Cable de cobre y soldadura | Conectar los sensores con el sistema eléctrico. |
| Base de PVC o madera reciclada | Dar soporte a la estructura. |
| Batería o condensador | Almacenar la energía, según la integración propuesta. |

## Proceso de construcción planteado

- Preparar la base de 30 × 30 cm.
- Distribuir y fijar los sensores en una matriz.
- Soldar las conexiones eléctricas.
- Instalar la cubierta protectora.
- Integrar y evaluar el sistema de almacenamiento o la carga de bajo consumo.

## Aplicaciones previstas

- Aprovechamiento de pisadas en zonas de alto tránsito.
- Alimentación de luces LED, sensores y dispositivos IoT de bajo consumo, según la energía realmente obtenida.
- Actividades educativas y demostraciones sobre sostenibilidad y conversión de energía.
- Exploración de superficies modulares con materiales reciclados.

## Alcance de esta entrega

Este repositorio reúne la **propuesta documental** del proyecto. El PDF describe el objetivo, el diseño, los materiales, el proceso de construcción, las aplicaciones y una evaluación preliminar de viabilidad. También incluye un **mockup conceptual generado con IA**, que no constituye evidencia de un prototipo construido.

El documento estima un costo aproximado de **USD 45 por baldosa**, sujeto a materiales y disponibilidad. Sus cifras de generación y capacidad de almacenamiento son estimaciones de la propuesta: no se acompañan de mediciones experimentales, un periodo de generación definido ni datos suficientes para validar el rendimiento. La capacidad expresada en mAh también requiere conocer la tensión para determinar la energía almacenada.

Esta entrega no incluye código fuente, planos eléctricos detallados ni resultados de pruebas de un prototipo físico.
